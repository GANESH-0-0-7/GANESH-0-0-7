how to creeate folder in github

GitHub doesn't let you create an empty folder. A folder exists only when it contains at least one file.

Method 1: Create a folder from the GitHub website (Recommended)
Open your repository.

Click Add file → Create new file.

In the file name box, type:
assets/coding.gif

or if you're creating the folder first:

assets/README.md

GitHub will automatically create the assets folder.
